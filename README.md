# StudyPrep 📚

StudyPrep is an AI-powered learning platform that helps students study faster by generating quizzes and flashcards from uploaded study materials.

## 🚀 Features

- 📄 Upload PDF study materials
- 🧠 AI-generated quizzes
- 🗂 AI-generated flashcards
- ⚡ Fast and simple interface
- 📚 Helps students revise quickly

## 🛠 Tech Stack

Frontend
- React
- Vite
- Tailwind CSS

Backend
- Node.js
- Express.js
- MongoDB

AI
- OpenAI API / AI model for quiz and flashcard generation
